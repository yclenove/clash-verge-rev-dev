# 2026-08-15 首页系统代理开关上移

日期：2026-08-15

## 变更摘要

首页顶栏在「代理服务地址」与「远程 DNS」之间显示系统代理开关；去掉合并卡上的「概览」标题行。

## 动机

系统代理是高频开关，放在「概览」行右侧既占一行，又和顶栏的远程 DNS 不在同一操作区。用户要求把它挪到顶栏，并删除只剩标题的概览行。

## 涉及文件

- `src/pages/home.tsx`
- `src/components/home/enhanced-card.tsx`
- `Changelog.md`

## 行为

- Windows / 桌面：系统代理开关出现在顶栏，样式与原先概览行右侧一致（开启时绿色）。
- OpenHarmony：顶栏仍不显示系统代理开关。
- 开关逻辑未改，仍走 `useSystemProxyState` / `handleSystemProxyToggle`。
- 合并卡仅保留内容区，不再渲染「概览」标题与图标。

## 迁移 / 重启

无需迁移。刷新或重新打开首页即可。无需重启内核。

## 验证

- `pnpm typecheck`
- 对照首页：顶栏顺序为 代理地址 → 系统代理 → 远程 DNS → 图标；内容区直接从当前节点开始，无「概览」行。
- 切换系统代理仍会更新状态且 busy 时禁用开关。
