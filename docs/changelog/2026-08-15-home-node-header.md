# 2026-08-15 首页顶栏按钮与当前节点布局

日期：2026-08-15

## 变更摘要

去掉首页顶栏远程 DNS 右侧的轻量模式、帮助图标。原设置按钮改为「更新订阅」，会刷新全部远程订阅。当前节点卡片内，延迟徽章在右上，全部节点 / 订阅筛选按钮在右下，不再单独占一整行。

## 动机

用户对照示意图：筛选按钮应贴在节点信息右侧；红圈内轻量/帮助去掉，设置改为更新订阅。

## 行为

- 顶栏保留代理服务地址、系统代理、远程 DNS，以及更新订阅。
- 首页区块显隐/排序对话框不再从顶栏打开（设置按钮已改为更新订阅）。
- 更新订阅会并行刷新全部 type=remote 的配置，并刷新节点列表。
- 订阅筛选改为节点信息框右侧的紧凑分段按钮，逻辑未改。

## 迁移 / 重启

无需迁移。重新编译或刷新前端即可。无需重启内核。
